## 🧭 How I ship

```text
1.  The user is a farmer, an operator, or a first-time investor — not a benchmark.
2.  Interpretability beats model size. A number without a reason is not an answer.
3.  Offline-first where it is possible. No GPU, no cloud dependency, no build step.
4.  Simulated is labelled SIMULATED. Every repo carries what it cannot do.
5.  Real screenshots, real tests, real limits — or it does not go in the README.
```
